# Standalone portfolio

Open `index.html` directly in Chrome or Edge. No server, Node.js, npm, or build step is needed.

## Files

- `index.html` contains the page content.
- `style.css` contains the responsive theme and layout.
- `script.js` provides the accessible mobile navigation and theme toggle.
- `assets/images/profile.jpeg` is the supplied profile photo.
- `assets/documents/resume.pdf` is the résumé linked from this page.

The résumé and profile photo are copies of `../public/resume.pdf` and `../public/profile.jpeg` used by the Next.js app. Keep the copies in sync when replacing either asset.

The page preserves the existing skills, projects, education, certifications, achievements, contact details, and repository links.
